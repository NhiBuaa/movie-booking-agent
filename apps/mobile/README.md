# Movie Booking Mobile App (`apps/mobile`)

Cross-platform mobile application (React Native / Expo) supporting both moviegoers and cinema on-ground staff.

## Responsibilities & User Roles
1. **Customer Mode (Moviegoer)**:
   - Browse movies, watch trailers, filter by cinema branch.
   - Interactive seat selection and fast mobile payment (MoMo, Apple Pay, Google Pay).
   - Conversational booking assistant (Buaa AI Agent).
   - Offline ticket storage and instantaneous QR code presentation at theater gates.
2. **Staff / Organizer Mode (On-ground Operations)**:
   - Camera-based high-speed QR ticket scanner for door validation.
   - Live auditorium check-in progress (seated vs. expected).
   - Emergency seat lock/unlock for broken physical seats.
